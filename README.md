# Retail Store Sales Analysis

## About the Project

This is a mini data analytics project based on retail store sales data.

The main goal of this project was to clean the raw data, analyze the sales information, and create an interactive dashboard using Excel and Power BI.

## Tools Used

- Microsoft Excel
- Microsoft Power BI

## What I Did

### 1. Data Cleaning – Excel

I cleaned the raw dataset by:

- Handling missing values
- Cleaning and standardizing item names
- Removing unwanted characters and symbols
- Correcting inconsistent values
- Recalculating missing values using related columns
- Standardizing the Discount Applied column
- Removing duplicate records

### 2. Data Analysis – Excel

After cleaning the data, I created PivotTables to analyze:

- Total Sales by Category
- Sales by Payment Method
- Yearly Sales
- Sales by Location and Category
- Average Sales by Category

### 3. Power BI Dashboard

I imported the cleaned data into Power BI and created an interactive dashboard.

The dashboard includes:

- Total Sales
- Total Quantity
- Average Price Per Unit
- Average Sales
- Total Sales by Category
- Total Sales by Payment Method
- Total Sales by Year and Month
- Total Sales by Category and Location
- Interactive slicers

## Key Insights

From the analysis, I found that:

- Food had the highest total sales.
- Digital Wallet was the most used payment method.
- Sales changed significantly across different months and years.
- In-store sales were higher than online sales in most categories.
